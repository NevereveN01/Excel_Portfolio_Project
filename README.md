# Bike Buyers Sales Dashboard | Excel Data Analysis Project
## 📋 Project Overview

This project demonstrates end-to-end data analysis skills using Microsoft Excel. The goal was to analyze customer data, identify key factors influencing bike purchases, and build a professional, interactive dashboard for the sales and marketing team. I was inspired by the excellent tutorials of [Alex The Analyst](https://www.youtube.com/c/AlexTheAnalyst) on YouTube. Following his practical style, I took a raw dataset and transformed it into a clean, insightful, and interactive business dashboard using only Microsoft Excel.

## 🛠 Skills & Tools Demonstrated

- **Microsoft Excel** (Advanced level)
- Power Query (Data cleaning & transformation)
- Power Pivot & DAX (Calculated measures and relationships)
- Pivot Tables & Charts
- Interactive Dashboard Design (Slicers, Buttons, Conditional Formatting)
- Data Modeling
- Exploratory Data Analysis (EDA)
- Insight Generation & Visualization Best Practices

## 📊 What Was Done

### 1. Data Cleaning & Preparation
- Standardized column names and data formats
- Fixed inconsistencies (e.g., "Maried" → "Married", "S" / "M" for Marital Status and Gender)
- Created new calculated fields:
  - `Age Group` (Adolescent, Middle Age, Old)
  - Cleaned and categorized `Age`
  - Normalized categorical variables

### 2. Exploratory Data Analysis
- Analyzed the impact of income, age, region, occupation, education, number of children, cars, and commute distance on bike purchases
- Identified high-potential customer segments

### 3. Interactive Dashboard

The final dashboard includes:

**Key Performance Indicators (KPIs):**
- Total Customers
- Bike Buyers
- Conversion Rate
- Average Income (Buyers vs Non-Buyers)

**Visualizations:**
- Purchase rate by Age Group
- Income distribution and its correlation with purchases
- Regional performance (Europe, Pacific, North America)
- Impact of Occupation and Education
- Effect of Number of Cars and Children
- Commute Distance analysis

**Interactivity:**
- Multiple slicers (Region, Age Group, Gender, Marital Status, Education, Occupation)
- Easy filtering for dynamic exploration

## 🎯 Key Insights 

- Middle-aged customers show significantly higher purchase rates
- Higher income brackets correlate with increased likelihood of buying
- Professionals and Management roles are the strongest buyer segments
- Regional differences in conversion rates were identified
- Customers with 0–1 cars are more likely to purchase a bike
